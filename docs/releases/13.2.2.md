## Changes since 13.2.1

- Updated the default Zulip Gold branding, including the sign-in screen, web app accents, favicon, and default app and email icons.
- Applied upstream security fixes for local uploads and Slack imports, and updated several Python dependency pins.
- Expanded the hybrid backend with additional opt-in Rust read paths and internal Rust processing. Django remains the default, and the migration does not require a deployment change.

## Platform notes

The server tarball was exercised with a fresh installation and an upgrade from Zulip 12.0 on Ubuntu 26.04. The release workflow builds a Linux amd64 container image with an Ubuntu 24.04 base.
